# MikroFIX — lokalni coderji in projektna orodja

Ta mapa ostane v razvojnem projektu. Tukaj so izvedbena pravila in zgodovinski
artefakti; profili lokalnih coder modelov ter zaganjalniki ostanejo v svojih
projektnih oziroma lokalnih tehničnih poteh. Lokalni
coder uporablja projektni [`CODER.md`](../../CODER.md) in konkretni lastnikov
cilj. Strokovni agenti Codex imajo fizično ločen repozitorij
[`/home/mikrofix/Codex_Agenti`](/home/mikrofix/Codex_Agenti/README.md) s
svojimi beležniki, sobo in zanje ustreznimi navodili; lokalnim coderjem teh
navodil ni treba brati ali izvajati.

Poslovna pravila ostajajo v projektnem [`docs/kanon/`](../kanon/00_KAZALO.md).
Aktivna programska naloga je `/home/mikrofix/Desktop/aktivna naloga.md` in
vsebuje en smiselno zaključen sklop. Git in poslovne odločitve niso coderjeva
odgovornost.

`PRAVILNIK_VERIGE.md` ter mape `roles/`, `supervisor/` in `dnevnik/`
opisujejo prejšnjo nadzorovano verigo in niso vzporedni aktivni postopek.
Mapa `pravila/` vsebuje generirane izvlečke kanona; `WORKSPACE.md` in
`LEKCIJE.md` nista nova vira poslovnih pravil.
