# Revizijski arhiv pravil pred uvedbo vlogovno neodvisne verige

Datum zajema: 25. 9. 2026

Mapa `original/` vsebuje nespremenjene kopije pravilnikov, njihovih izvirnikov,
promptov, shem in registrov, ki so bili prisotni tik pred konsolidacijo sedanje
verige lokalnih agentov. Relativne poti so ohranjene.

`SHA256SUMS` je bil izdelan nad vsemi 42 kopijami in ob zajemu uspešno preverjen
z `sha256sum --check --strict`. Ta arhiv je revizijski dokaz, ne aktivni vir
navodil za modele ali izvajanje.
